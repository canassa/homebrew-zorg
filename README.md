# canassa/zorg

Homebrew tap for [zorg](https://github.com/canassa/zorg), a Zig compiler
fork with a self-hosted AArch64 backend.

```sh
brew install canassa/zorg/zorg
```

zorg installs as `zorg` and keeps its standard library and cache apart
from an upstream `zig`, so both can be installed side by side.

Supported: macOS on Apple silicon, Linux on x86_64 and aarch64.

`Formula/zorg.rb` is generated by the release workflow in
[canassa/zorg](https://github.com/canassa/zorg/blob/master/.github/workflows/release.yml)
from `.github/zorg/zorg.rb.in`. Change the template there, not the
formula here.
